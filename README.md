# Dotfiles

Personal configuration managed with [chezmoi](https://www.chezmoi.io/).

- **Bash** — aliases, history settings, and optional Homebrew, eza, zoxide, and Starship integration.
- **Readline** — case-insensitive completion and prefix-based history search.
- **Git** — aliases, diff preferences, global ignore rules, and a local configuration include.
- **Starship** — custom prompt with Git status and language information.
- **eza** — a One Dark-inspired color theme.
- **Zed** — editor settings, extensions, and language preferences.
- **Konsole** — a matching Custom profile and colorscheme using Cousine Nerd Font.
- **Micro** — indentation, line numbers, syntax highlighting, and save preferences.
